# Build a portfolio, one complete slice at a time

[Roadmap](../README.md) · [Study schedule](../STUDY_PLAN.md)

| Project | What actually runs | What you learn |
| --- | --- | --- |
| [Documentation assistant](docs-assistant/README.md) | Offline BM25 excerpts; optional live hybrid retrieval and generated citations | Retrieval, embeddings, prompts, abstention, evaluation |
| [Support approval workflow](support-workflow/README.md) | In-process action preparation, payload-bound simulated approval, replay prevention | Authorization, idempotency, human review |
| [HTTP retrieval API](rag-api/README.md) | Local Node.js server returning permission-filtered excerpts | Validation, body limits, HTTP contracts, integration tests |

These are runnable learning projects with deliberately small fixtures. Each project README distinguishes its implemented behavior from your extension work. They are starting points for a portfolio, not complete production deployments.

For each extension, include a setup command, architecture diagram, versioned evaluation set, measured results, failure analysis, and limitations. Never publish real keys, private tickets, or employer documents.
